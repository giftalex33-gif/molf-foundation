MOLF WEBSITE STARTER PACKAGE

Project: MOLF — Mute Olori Leadership Development Foundation

Pages included: index.html, about.html, programs.html, gallery.html, the-parenting-journal.html, letters.html, podcast.html, volunteer.html, contact.html, donate.html, register.html.

HOW TO OPEN
1. Extract the ZIP.
2. Open index.html in a browser.

IMPORTANT
- The design uses remote Unsplash images as illustrative placeholders. An internet connection is needed to load them. Replace these with the original MOLF photographs before publishing.
- This is a front-end website template. Forms open a mailto draft; they do not save data to a server.
- No PHP/MySQL admin backend is included in this package.
- Update official email, address, donation information, program details, legal/privacy content and social links before launch.
- The site has responsive styling and a working client-side gallery category filter.
